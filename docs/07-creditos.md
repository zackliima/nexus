# 07 — Créditos e recursos

## Implementação e ilustrações

O HTML, CSS, scripts de aplicação, favicon, esfera SVG, ilustração de hipertexto e diagramas inline são originais deste experimento, produzidos com assistência de IA. O telefone é uma composição conceitual em CSS. Nenhuma ilustração é apresentada como fotografia ou documento histórico.
